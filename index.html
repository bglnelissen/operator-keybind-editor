Activation types

The Type column decides when an action fires — not which key fires it. That is how one key can carry more than one action.

Press
Fires the moment the key goes down. The plain, immediate option.
Toggle
Only on Aim Weapon, where the game labels Press as Toggle: one tap goes into the sights, the next tap comes back out, instead of firing once.
Release
Fires when you let the key go. Useful as the partner of a Hold on the same key: hold it for one action, and the release does something else.
Hold
Stays active for as long as the key is down and stops when you let go. What you want for anything continuous — leaning, sprinting, holding breath, panning the ATAK.
Double Click
Fires on two quick taps.
Hold Delayed
Fires only after the key has been down for a moment. This is the one that makes stacking work: the game waits to see whether a tap, a double tap or a real hold is coming, so a plain Hold on a shared key would fire too early.

Stacking example from the Numpad preset: Keypad Enter runs on Hold Delayed and sprints on Double Click; Keypad 2 kicks on Release and vaults on Hold Delayed. Two actions only clash when the key and the type match.

Type names are taken from the game’s own keybind screens. The behaviour is pieced together from in-game testing and community guides — the game ships no manual for it.
